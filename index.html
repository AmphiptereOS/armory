Amphiptere Sentinel Integrated in Amphiptere OS

What is Amphiptere Sentinel?

Amphiptere Sentinel is a perimeter defense tool. It manages system firewall rules (iptables) and listens on TCP port 9999 to secure access using a temporary passcode mechanism.

About

Sentinel is pre-installed and configured within Amphiptere OS to provide system-level perimeter defense.

Commands

Enable Defense

sudo go run amphiptere.go --enable

Disable Defense

sudo go run amphiptere.go --disable

Check Status

sudo go run amphiptere.go --status

Amphiptere-Ops Integrated in Amphiptere OS

What is Amphiptere-Ops?

Amphiptere-Ops is a unified purple team utility. It performs simulated vulnerability scanning alongside defense verification and compiles results into a structured text report.

Workflow

  • Banner & Authorization Display: Prints the tool banner and authorization notice.
  • Phase 1 - Red Team Scan: Cycles through simulated weaknesses such as open ports, outdated packages, and loose file permissions.
  • Phase 2 - Blue Team Verification: Verifies defensive controls and outputs pass/fail metrics.
  • Phase 3 - Report Generation: Saves results locally to report.txt.
go run amphiptere-ops.go

Acid Cracker Integrated in Amphiptere OS

What is Acid?

Acid is an offline high-performance password and hash-cracking tool written in Go. It performs wordlist-based SHA-256 brute-force evaluations for security assessments and audits.

go run acid.go -hash <sha256_hash> -wordlist <path_to_wordlist.txt>

OWL-Auditor Integrated in Amphiptere OS

What is Owl-Auditor?

Owl-Auditor is a lightweight host and attack surface intelligence engine. It performs localized security audits to inspect system configurations, file permissions, firewall statuses, and active listening ports.

go run owl-auditor.go
go run owl-auditor.go -ip <target_ip>

Huntdd-Ghost Open Source

What is Huntdd-Ghost?

Huntdd-Ghost is a lightweight, local-only filesystem auditing tool written in Go. It performs deep enumeration and hash-based audits to scan directories for sensitive files, misconfigurations, and insecure permissions.

Availability

This tool is open-source and available for public use as a preview from the Amphiptere Armory.

Commands

Default Scan

go run huntdd.go

Custom Target Scan

go run huntdd.go -scan <directory_path>
