Amphiptere Sentinel Integrated in Amphiptere OS

What is Amphiptere Sentinel?

Amphiptere Sentinel is a perimeter defense tool. It manages system firewall rules (iptables) and listens on TCP port 9999 to secure access using a temporary passcode mechanism.

About Amphiptere Sentinel

Written in Go. Amphiptere Sentinel is pre-installed and configured within Amphiptere OS to provide system-level perimeter defense. It is an integrated component of Amphiptere OS.

Amphiptere Sentinel Commands

To run or manage the tool inside Amphiptere OS, execute it with root or sudo privileges:

Enable Defense

sudo go run amphiptere.go --enable

Disable Defense

sudo go run amphiptere.go --disable

Check Status

sudo go run amphiptere.go --status

Amphiptere-Ops Integrated in Amphiptere OS

What is Amphiptere-Ops?

Amphiptere-Ops is a unified purple team utility written in Go. It performs simulated vulnerability scanning (red team perspective) alongside defense verification (blue team perspective), and automatically compiles the results into a structured text report.

About Amphiptere-Ops

Amphiptere-Ops is an integrated utility within Amphiptere OS environment designed for purple team assessments.

Amphiptere-Ops Commands

To run the tool inside Amphiptere OS:

go run amphiptere-ops.go

What Happens When You Run It:

  • Banner and Authorization Display: Prints the tool banner and notices the authorization disclaimer.
  • Phase 1 (Red Team Scan): Automatically cycles through simulated weaknesses and misconfigurations (such as Open Port 22, outdated packages, loose file permissions, and default configurations).
  • Phase 2 (Blue Team Verification): Verifies corresponding defensive controls, checks logs/firewalls, and outputs pass/fail status metrics.
  • Phase 3 (Report Generation): Compiles all data and saves it locally into a text file named report.txt.

Acid Cracker Integrated in Amphiptere OS

What is Acid?

Acid is an offline high-performance password and hash-cracking tool written in Go. It performs wordlist-based SHA-256 brute-force evaluations for security assessments, audits, and password testing.

About Acid Cracker

Acid is an integrated security assessment tool within Amphiptere OS, optimized for offline hash evaluation.

Acid Commands

To run the tool inside Amphiptere OS:

go run acid.go -hash <sha256_hash> -wordlist <path_to_wordlist.txt>

OWL-Auditor Integrated in Amphiptere OS

What is Owl-Auditor?

Owl-Auditor is a lightweight, high-performance host and attack surface intelligence engine written in Go. It performs localized security audits to inspect system configurations, file permissions, firewall statuses, and active listening ports before adversaries can leverage them.

About Owl-Auditor

Owl-Auditor is an integrated auditing engine within Amphiptere OS for host-level attack surface intelligence.

Owl-Auditor Commands

To run the tool inside Amphiptere OS:

go run owl-auditor.go

For target-specific audit:

go run owl-auditor.go -ip <target_ip>

Huntdd-Ghost Open Source

What is Huntdd-Ghost?

Huntdd-Ghost is a lightweight, local-only filesystem auditing tool written in Go. It performs deep enumeration and hash-based vulnerability audits to scan directories for sensitive files, misconfigurations, and insecure permissions.

About Huntdd-Ghost

Huntdd-Ghost is the only open-source tool from Amphiptere Armory. It is available for public use as a preview from the Armory and is also integrated in Amphiptere OS.

Huntdd-Ghost Commands

Default Scan (Current Directory)

go run huntdd.go

Custom Target Scan Path

go run huntdd.go -scan <directory_path>

Example:

go run huntdd.go -scan /path/to/your/files
